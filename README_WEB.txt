BLUNNO CONTROL EMPRESARIAL — INSTALACIÓN FINAL

1) Descomprimir el ZIP.
2) La carpeta resultante es el proyecto completo.
3) Para GitHub Pages, subir el contenido de la carpeta al repositorio.
4) Para Netlify, desplegar el contenido de la carpeta como raíz del sitio.
5) Abrir index.html mediante un servidor web; no se recomienda trabajar con file:// para todas las funciones.
6) Elegir responsable una vez al iniciar la sesión.
7) Elegir sucursal antes de cargar movimientos.
8) Caja diaria no forma parte del Resultado.
9) Para PDFs, el responsable debe estar seleccionado; el PDF se genera, se archiva y queda disponible para volver a descargarlo.
10) Para nube, completar las credenciales Firebase en config.js y configurar Firestore/Storage/Rules.
