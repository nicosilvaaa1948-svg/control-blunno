GITHUB PAGES — BLUNNO V17 ESTABLE WEB

Esta versión está preparada para GitHub Pages y evita el error de versiones anteriores.

1. Descomprimí el ZIP.
2. La carpeta BLUNNO_CONTROL_EMPRESARIAL_FINAL_WEB contiene todo el proyecto.
3. Subí TODOS sus contenidos al directorio raíz del repositorio de GitHub.
4. index.html debe quedar directamente en la raíz.
5. La página incluye el runtime completo embebido dentro de index.html y además conserva blunno-control.js como archivo fuente independiente.
6. No se usa web.js de versiones anteriores y no se usa PWA/service worker.
7. Settings → Pages → Deploy from branch → main → /(root).
8. Esperá el deployment y hacé Ctrl+Shift+R.

La aplicación arranca en Modo local mientras Firebase no tenga credenciales reales.
No cargues datos ficticios. El sistema comienza sin movimientos económicos de prueba.
